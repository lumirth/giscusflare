giscusflare

GitHub Discussions comments you can customize and deploy on Cloudflare.

Use the familiar default interface, change individual components, or design a comments section to match your website. The shared conversation API handles sign-in, drafts, replies and reactions.

GitHub · Customization · Try the demo

How it works

Each page on your website maps to a GitHub discussion. Visitors sign in with GitHub to comment or react. You can reply and moderate on your website or on GitHub.

Your Cloudflare Worker connects the website to GitHub. Its setup page walks you through creating a GitHub App, choosing a repository and allowing your website. Then you paste the generated script into your site.

Customization

  • Use the supplied themes or style individual components.
  • Embed in an iframe or mount directly in your page.
  • Build a different interface with the same authentication, editing and draft behavior.

The forum example has its own markup and styles. Read its source or start with the customization guide.

Compared with giscus

giscus provides a hosted comments service. You deploy giscusflare on Cloudflare and use its JavaScript API to customize the interface. Both use repositories you choose.

Read about the differences, Cloudflare usage, and service configuration.
