1. Connect GitHub

Choose a public repository with Discussions enabled. This is where comments will live. It can be separate from your copy of the giscusflare source.

Register a public App so visitors can sign in. On GitHub, clear Allow wildcard matching for the callback address. Register on GitHub

After registering, generate a client secret and a private key. Choose Install App and select your comments repository.

2. Configure Cloudflare

Open your Worker's Settings, then Variables and Secrets.

Add each value below as a text variable. Use JSON for REPOSITORIES.

Add these encrypted secrets:

  • GITHUB_CLIENT_SECRET, the client secret from GitHub.
  • GITHUB_PRIVATE_KEY, the full contents of the downloaded PEM file.
  • SESSION_SECRET, a random key generated below.

Save and deploy the settings, then check your repository below. Keep the same session secret when updating giscusflare so readers stay signed in.
